# Exercise images / Imagenes de ejercicios

Use the same base names as the videos, with .jpg or .png extensions.
Usa los mismos nombres base de los videos, con extension .jpg o .png.

- sentadilla.jpg
- zancada.jpg
- peso_muerto_rumano.jpg
- elevacion_pantorrillas.jpg
- step_up.jpg

PNG is also supported. Images are optional and ignored by Git by default.
Tambien se admite PNG. Las imagenes son opcionales y Git las ignora por defecto.
